# Tab Cycler website

Static homepage and privacy policy for Tab Cycler. No build step or runtime dependencies.

Public website source: https://github.com/tungfam/TabCycler-site

Published home: https://tungfam.github.io/TabCycler-site/

Privacy policy: https://tungfam.github.io/TabCycler-site/privacy/

The public website repository contains only this directory's contents. The extension source remains in the separate private TabCycler repository. Keep both website copies synchronized when editing; GitHub Pages deploys from the public repository's main branch root.

Preview locally by serving this directory with a static HTTP server. The homepage's small interactive example uses sample tab labels and does not interact with browser tabs.
