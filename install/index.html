Try Tab Cycler today.

The Chrome Web Store release is on its way. Until then, download the extension and install it manually. No build tools or account required.

Download ZIP · v0.2.9 ↓

The ZIP includes the extension and a Ukrainian installation guide. You can also send the ZIP directly to a friend.

1. Unzip and keep the folder

Double-click the downloaded ZIP. Move the extracted TabCycler folder somewhere permanent, such as your Documents folder. Keep it there while the extension is installed; Chrome loads its files from this folder.

2. Load it in Chrome

  1. Type chrome://extensions into Chrome’s address bar.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked.
  4. Select the extracted TabCycler folder containing manifest.json.

Select the folder, rather than the ZIP file. Existing ordinary webpages are initialized automatically; refreshing every page is not required.

3. Check your shortcuts

Type chrome://extensions/shortcuts into the address bar. Find TabCycler and check these commands:

  • Open recent tab switcher: ⌘ ⇧ Y by default. You can choose your own combination.
  • Duplicate current tab to its right: ⌘ ⇧ J.

If a shortcut is blank or conflicts with another command, assign an available combination. Keep its scope set to In Chrome.

4. Give it a try

Visit a few tabs, then focus a webpage. Press your switcher shortcut and keep holding Command. Use ← / → or press the shortcut again to browse. Release Command to switch. A quick tap returns to the previous tab without showing the cycler.

Keyboard release detection needs webpage focus. The cycler cannot appear on Chrome’s internal pages, the Chrome Web Store, or other protected pages. If Command release is missed, use Enter to select. Windows and Linux support has not been validated.

Updating later

This manual installation does not update automatically. Download a newer ZIP, unpack it, replace the contents of your existing TabCycler folder, then click Reload on its card at chrome://extensions. Keep the same folder location to preserve the installation and shortcut settings.
