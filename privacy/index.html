PRIVACY, IN PLAIN LANGUAGE

Your tabs stay your business.

Tab Cycler has no backend, analytics, or advertising. It uses tab information locally in Chrome to help you switch between recently used tabs.

Last updated: 7 November 2026 · Developer: Tung Fam

What the extension uses

Tab Cycler accesses open-tab identifiers, titles, URLs, favicon addresses, window information, and tab activation events. It uses this information to order tabs by recent use and display their titles, domains, and icons. The cycler shows up to eight recent tabs in the current window.

Keyboard listeners handle navigation and modifier release for the cycler. The extension does not record text you type into webpages, read passwords, extract page contents, or take screenshots.

What is stored, and for how long

Recent-tab identifiers, their ordering, and temporary switching-session details are kept in Chrome’s session storage. Tab titles, URLs, and favicon addresses are used in memory for the cycler, rather than saved as a persistent browsing-history database.

Session storage survives suspension of the extension’s background worker. Chrome clears it when the browser restarts or the extension is disabled, reloaded, or updated. Closed tabs are removed from the recent-tab ordering. You can also remove the extension through Chrome’s extension settings.

Why the permissions are needed

  • Tabs: read tab titles, URLs, and favicon addresses to identify the tabs shown in the cycler.
  • Storage: maintain recent-tab ordering and temporary switching sessions locally.
  • Scripting: initialize already-open webpages on installation or update, and recover missing initialization without refreshing the page.
  • HTTP and HTTPS website access: display the cycler over webpages and receive the keyboard events needed for navigation and Command-release selection.

Chrome’s permission wording describes what these permissions allow. Tab Cycler uses them for its tab-switching functionality. Chrome restricts extensions on certain pages, and you can control website access through Chrome’s extension settings.

Network requests and third parties

We do not operate a backend that receives your tab history or tab contents. We do not sell browsing data or use it for advertising or analytics.

To display favicons, Chrome may load icon images from the website or icon address associated with a tab. Those image requests go to the relevant site or icon host, which may receive ordinary network-request information such as your IP address. The extension sets no-referrer on these images and does not upload your recent-tab list with them.

This website

This website is hosted on GitHub Pages. It does not add advertising, analytics, tracking scripts, contact forms, or account registration. GitHub Pages records visitors’ IP addresses for security purposes, as explained in GitHub’s documentation and the GitHub Privacy Statement. Following an external link is subject to that service’s policies.

Limited use

Tab Cycler uses browsing-related information only to provide its tab-switching feature, consistent with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes to this policy

We will update this page and its date when the extension’s data handling changes. This policy describes the current extension; future features are not covered by permissions requested in advance.
